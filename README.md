# 回看 · 北极星复盘

[打开北极星复盘](https://molly-gith.github.io/northstar/)

网站由 GitHub Pages 直接提供，不再跳转到 Vercel。使用原来的邮箱和密码登录，即可继续访问已同步的云端记录。

- 月度与年度总表、每日记录、九宫格、记账与回顾。
- 忍者日志：从主页面一行入口打开弹窗，记录与回顾集中处理；支持保存后连续补录，手机电脑登录同一账号同步。
- 忍者日志 AI 试用：指定账号可说一段话或写一段文字，由百炼整理为可修改草稿，确认后才保存。手动记录继续可用；服务端限制账号、次数和试用期限，免费额度用尽即停。
- 喝水记录：独立弹窗，一键记录喝完 500 mL，支持其他水量、补录、撤销和本月回看，沿用账号同步。
- 图片、PDF、打印和 JSON 备份。
- Supabase 提供原有账号和按账号隔离的数据；个人记录不保存在此公开仓库。

换到新网址后需重新登录一次。旧网址尚未同步的本机草稿，请先等待保存或下载备份。

此仓库只发布网站构建产物。私有源码保存在 Molly-gith/northstar-review 的 github-pages 分支。
