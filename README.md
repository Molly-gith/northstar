# 回看 · 北极星复盘入口

这个公开仓库只提供 GitHub Pages 访问入口。打开入口后，会立即跳转到现有复盘应用：

[GitHub 网页入口](https://molly-gith.github.io/northstar/)

[直接进入回看 · 北极星复盘](https://northstar-review-mu.vercel.app/)

复盘应用实际运行在 Vercel，应用代码的主仓库保持私有。这个入口仓库不包含复盘应用源码、个人复盘内容、邮箱、密钥或登录凭据。入口公开不改变原应用的登录与数据权限。

## 跳转方式

- 启用 JavaScript 时，使用 `location.replace` 跳转，避免返回按钮重复经过入口。
- 禁用 JavaScript 时，使用 HTML 自动刷新跳转。
- 页面保留“进入复盘”链接，自动跳转不可用时可手动进入。

目标是固定的 HTTPS 地址。入口不读取或转发访问地址中的查询参数和片段，不嵌入应用，不含统计脚本、表单或存储逻辑；并设置不向目标发送来源地址。

## 发布与维护

将本目录的 `index.html`、`README.md` 和 `.nojekyll` 放在独立公开仓库根目录，在仓库的 Pages 设置中选择从该分支根目录发布即可，无需构建。

如果以后更换应用地址，请同步修改 `index.html` 中的自动跳转、无 JavaScript 跳转、手动链接及 canonical 地址，并更新本说明中的链接。只有入口代码需要放入此仓库，私有应用代码继续留在原主仓库中。
